About the project

An end-to-end data project built to investigate how Liebe ist für alle da evolved from a 2009 release into a long-term digital and live catalogue.

PROJECT QUESTION

What separates release-era success from long-term legacy?

The project combines track metadata, Spotify streaming snapshots, Last.fm engagement, documented live performances, international chart results and certification records.

Rather than treating popularity as one number, the analysis separates audience size, repeat listening, current momentum, live persistence and commercial reach.
